# Study Archive
통합 학습 콘텐츠 아카이브입니다. 물리학, 수학, 영어, 일본어, 역사, 화학, 생물학, 지구과학 자료를 과목별로 관리합니다.

## 공개 자료실
GitHub Pages를 활성화하면 메인 페이지에서 과목별 자료를 찾아볼 수 있습니다.

## 폴더 규칙
- 과목 폴더 안에 주제별 하위 폴더를 만듭니다.
- 각 학습 콘텐츠는 독립 실행 가능한 HTML 페이지로 제작합니다.
- 여러 콘텐츠에서 공통으로 쓰는 이미지·스타일·스크립트는 `resources/`에 둡니다.
- Blogger에는 공개된 콘텐츠 주소를 iframe으로 삽입할 수 있습니다.

## 과목
- [물리학](./physics/) — 운동학, 역학, 열역학, 전자기학, 파동, 현대물리학과 인터랙티브 시뮬레이션
- [수학](./mathematics/) — 수와 연산, 대수, 함수, 기하, 확률과 통계, 미적분 및 그래프 도구
- [영어](./english/) — 문법, 어휘, 독해, 듣기, 회화, 발음 및 인터랙티브 퀴즈
- [일본어](./japanese/) — 문법, 어휘, 한자, 독해, 듣기, 회화 및 학습 퀴즈
- [역사](./history/) — 한국사, 세계사, 일본사, 연표, 지도 및 역사 자료
- [화학](./chemistry/) — 원자와 분자, 화학 결합, 반응, 열화학, 산·염기 및 분자 시뮬레이션
- [생물학](./biology/) — 세포, 유전, 진화, 생리, 생태 및 생명과학 시각화
- [지구과학](./earth-science/) — 지질, 대기, 해양, 천문 및 지구 시스템 시각화
